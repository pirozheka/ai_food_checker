# 🍎 Calorie Bot — калорийность еды по фото

Telegram-бот, который по фотографии блюда и/или текстовому описанию оценивает
калорийность и БЖУ через vision-модель на [OpenRouter](https://openrouter.ai).

## Возможности

- 📷 **Фото блюда** → название, вес порции, ккал, белки/жиры/углеводы, разбивка по компонентам
- 📦 **Фото штрихкода** на упаковке → точные КБЖУ с этикетки из Open Food Facts (бесплатно, без OpenRouter), бот спрашивает съеденный вес
- ✍️ **Текстовое описание** («овсянка на молоке 250 г и банан») → та же оценка
- 📝 Подпись к фото уточняет оценку («порция 300 г», «жарено без масла»)
- 🕐 **Запись задним числом**: `/add вчера борщ 300 г`, `/add пн овсянка`, `/add 5.09 кофе`; с фото — начните подпись с дня («вчера, порция 300 г»)
- 📊 Дневник за день: `/today`, `/day вчера`, `/undo`, `/clear`, кнопка «Убрать из дневника» под каждой записью
- 📈 **Итоги недели**: `/week` (и `/week прошлая`) — калории по дням, среднее, баланс БЖУ и краткий разбор от модели
- 📬 В воскресенье вечером бот сам присылает недельный отчёт
- 🎯 Модель сообщает уровень уверенности и допущения (масло, заправка, скрытые калории)
- 🔒 Приватный доступ: работает только для ID из `ALLOWED_USER_IDS`

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

Для чтения штрихкодов (`pyzbar`) нужна системная библиотека zbar:

```bash
# Debian/Ubuntu
sudo apt-get install -y libzbar0
# macOS
brew install zbar
```

Заполните `.env`:

| Переменная | Обязательна | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен от [@BotFather](https://t.me/BotFather) |
| `OPENROUTER_API_KEY` | да | ключ с https://openrouter.ai/keys |
| `OPENROUTER_MODEL` | нет | модель с vision, по умолчанию `google/gemini-2.5-flash` |
| `TIMEZONE` | нет | для подсчёта «за сегодня», по умолчанию `Europe/Moscow` |
| `ALLOWED_USER_IDS` | нет | белый список ID через запятую; по умолчанию `349106724,1217167250,631012438`, пустое значение = доступ всем |
| `DB_PATH` | нет | файл SQLite, по умолчанию `food.db` |
| `WEEKLY_REPORT_HOUR` | нет | час воскресного отчёта в локальной зоне, по умолчанию `20` |

## Запуск

```bash
.venv/bin/python bot.py
```

Бот работает на long polling — публичный адрес и вебхук не нужны.

## Доступ

Бот приватный: сообщения и нажатия кнопок принимаются только от ID из
`ALLOWED_USER_IDS` (по умолчанию `349106724`, `1217167250` и `631012438`). Остальным приходит
отказ с их собственным ID — удобно, чтобы добавить человека в список.
Разрешён также чат, чей `chat.id` есть в списке (для групп).

Чтобы открыть бота всем, оставьте `ALLOWED_USER_IDS=` пустым — при старте
в лог уйдёт предупреждение.

## Выбор модели

Подойдёт любая модель OpenRouter с поддержкой изображений
([список](https://openrouter.ai/models?modality=text+image-%3Etext)):

- `google/gemini-2.5-flash` — дёшево, быстро, хорошо считает порции (по умолчанию)
- `openai/gpt-4o-mini` — дешёвая альтернатива
- `anthropic/claude-sonnet-4.5` — самая аккуратная разбивка по ингредиентам, дороже

Если модель не умеет structured outputs, клиент автоматически повторяет запрос
без `response_format` и разбирает JSON из текста.

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | хендлеры Telegram, форматирование ответа, точка входа |
| `openrouter.py` | HTTP-клиент OpenRouter, ретраи, парсинг ответа модели |
| `barcode.py` | чтение штрихкода с фото (`pyzbar`) и поиск товара в Open Food Facts |
| `prompts.py` | системный промпт и JSON-схема ответа |
| `storage.py` | SQLite-дневник приёмов пищи, агрегация недели |
| `config.py` | настройки из окружения |

## Точность

Оценка по фото — приблизительная: модель не видит вес и жирность продуктов.
Типичная ошибка — 15–30%, больше для соусов, масла и скрытых ингредиентов.
Указывайте вес в подписи, если он известен. Это не медицинская рекомендация.
